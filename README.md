# Teacher's Test Maker

Build a simple web app for grade school teachers to generate sample tests from lesson pointers. The app must support multiple-choice questions with 4 options, correct answers, optional short explanations, and export to PDF or Word. Include English, Tagalog, and mixed English-Tagalog modes. Make the UI clean, mobile-friendly, and easy for non-technical users. Include screens for Home, Create Test, Preview/Edit, Export, and Saved Tests. Keep the first version focused on one clear workflow: enter pointers, generate test, review, and download
